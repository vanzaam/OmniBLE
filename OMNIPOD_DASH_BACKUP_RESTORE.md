# 🔐 Omnipod DASH - Бэкап и восстановление состояния пода

## 📋 **Краткое резюме**

**Можно ли восстановить DASH на другом iPhone?**
- ❌ **НЕТ** - при ручном переносе данных
- ✅ **ДА** - при восстановлении из полного бэкапа iPhone

**Почему так?**
- DASH использует **криптографическую привязку** к конкретному iPhone через LTK (Long Term Key)
- LTK генерируется через **ECDH (X25519)** при первом сопряжении
- iOS сохраняет **Bluetooth UUID** в системном бэкапе
- При восстановлении iPhone из бэкапа → Bluetooth UUID остается тем же → под работает!

---

## 🔍 **Как это работает?**

### **Процесс первичного сопряжения DASH:**

```
1. Телефон генерирует случайный приватный ключ X25519
2. Телефон генерирует случайный nonce (16 байт)
3. Телефон ↔ Под: Обмен публичными ключами через BLE
4. Обе стороны вычисляют shared secret через ECDH
5. LTK = AES-CMAC(shared secret, nonces, magic strings)
6. Под сохраняет: LTK + Bluetooth UUID телефона
7. Телефон сохраняет: LTK + Pod Address + Bluetooth UUID пода
```

**Результат:**
- LTK **уникален** для каждой пары телефон-под
- LTK **невозможно перенести** на другой телефон вручную
- Под **привязан** к Bluetooth UUID первого телефона

---

### **Что происходит при восстановлении iPhone из бэкапа:**

```
Старый iPhone:
├─ Bluetooth UUID пода: 308132DE-59E2-C439-E198-21651962B595
├─ LTK: a1b2c3d4e5f6...
└─ PodState сохранен в бэкапе

↓ Восстановление на новый iPhone ↓

Новый iPhone:
├─ iOS восстанавливает Bluetooth-стек
├─ Peripheral получает ТОТ ЖЕ UUID: 308132DE-59E2-C439-E198-21651962B595 ✅
├─ FreeAPS X восстанавливает PodState из бэкапа
├─ bleIdentifier совпадает с iOS Bluetooth UUID ✅
└─ Под подключается и работает! 🎉
```

**Магия iOS:**
- iOS **не генерирует новый UUID** для peripheral при восстановлении
- iOS **сохраняет привязку** UUID → физическое устройство
- iOS **восстанавливает эту привязку** на новом iPhone

---

### **Почему НЕ работает при ручном переносе:**

```
Старый iPhone:
└─ bleIdentifier: 308132DE-59E2-C439-E198-21651962B595

↓ Ручное копирование данных ↓

Новый iPhone:
├─ iOS НЕ знает о старом Bluetooth UUID
├─ iOS генерирует НОВЫЙ UUID: AAAABBBB-CCCC-DDDD-EEEE-FFFFFFFFFFFF ❌
├─ FreeAPS X ищет: 308132DE-59E2-C439-E198-21651962B595
└─ Под НЕ подключается ❌
```

## 💾 **Что сохраняется в бэкапе:**

### **Критические данные:**
```swift
struct OmniBLEPodStateBackup {
    // КРИТИЧНО для восстановления:
    let address: UInt32              // Pod ID (0x1f123456)
    let ltk: Data                    // Long Term Key (16 байт)
    let bleIdentifier: String        // Bluetooth UUID
    
    // Состояние сессии:
    let ck: Data?                    // Session encryption key
    let noncePrefix: Data?           // Nonce prefix
    let eapSeq: Int                  // EAP sequence counter
    let msgSeq: Int                  // Message sequence number
    
    // Информация о поде:
    let firmwareVersion: String
    let lotNo: UInt32
    let activatedAt: Date?
    let expiresAt: Date?
    // ... и другие поля
}
```

## 🛠️ **Использование UI для бэкапа/восстановления:**

### **1. Просмотр информации о поде:**

```
Настройки → Помпа → Бэкап/Восстановление пода

Информация о текущем поде:
├─ Pod ID: 0x1F123456
├─ Bluetooth UUID: 308132DE-59E2...
├─ Firmware: 2.9.0
├─ Статус: Активирован ✅
├─ Активирован: 29.11.2025 14:00
└─ Истекает: 02.12.2025 22:00
```

### **2. Экспорт бэкапа:**

```
1. Нажмите "Создать JSON бэкап"
2. JSON отобразится на экране
3. Нажмите "Копировать в буфер обмена"
4. Сохраните JSON в безопасном месте (Notes, Files, Email)
```

**Пример JSON:**
```json
{
  "version": 1,
  "createdAt": "2025-11-29T14:00:00Z",
  "deviceModel": "iPhone15,3",
  "iosVersion": "17.0",
  "address": 520093750,
  "ltk": "a1b2c3d4e5f6...",
  "bleIdentifier": "308132DE-59E2-C439-E198-21651962B595",
  "firmwareVersion": "2.9.0",
  ...
}
```

### **3. Импорт бэкапа:**

```
1. Нажмите "Восстановить из JSON"
2. Вставьте JSON из буфера обмена
3. Нажмите "Восстановить из бэкапа"
4. Приложение попытается переподключиться к поду
```

**⚠️ ВАЖНО:**
- Бэкап работает **ТОЛЬКО на том же iPhone**
- Или при **восстановлении из полного бэкапа iPhone**
- Bluetooth UUID должен совпадать с iOS Bluetooth-стеком

## 🔐 **Безопасность:**

### **Что защищает DASH:**
- ✅ **LTK уникален** для каждого телефона
- ✅ **Криптографическая привязка** через ECDH
- ✅ **Session keys** меняются при каждом подключении
- ✅ **EAP-AKA** для установки сессии

### **Что нужно защищать:**
- 🔒 **JSON бэкап** - содержит LTK (16 байт)
- 🔒 **Полный бэкап iPhone** - содержит все данные
- 🔒 **iCloud бэкап** - если включен

### **Рекомендации:**
- Сохраняйте JSON бэкап в зашифрованном хранилище
- Используйте шифрование бэкапов iPhone
- Не делитесь JSON бэкапом с другими
- Удаляйте старые бэкапы после замены пода

## 🚨 **Частые вопросы:**

### **Q: Можно ли использовать один под на двух iPhone?**
**A:** ❌ НЕТ. Под привязан к первому iPhone через LTK.

### **Q: Можно ли перенести под на новый iPhone вручную?**
**A:** ❌ НЕТ. Только через полный бэкап iPhone.

### **Q: Что делать если потерял JSON бэкап?**
**A:** Ничего страшного. FreeAPS X автоматически сохраняет PodState в:
- UserDefaults (primary)
- FileStorage (backup)
- device_state_backup.json (triple protection)

### **Q: Можно ли восстановить под после сброса iPhone?**
**A:** ✅ ДА, если восстанавливаете из полного бэкапа iPhone.
❌ НЕТ, если настраиваете iPhone как новый.

### **Q: Зачем нужен JSON бэкап если есть автоматический?**
**A:** Для:
- Ручного восстановления после переустановки приложения
- Переноса между разными версиями FreeAPS X
- Диагностики проблем с подключением
- Резервного копирования в облако

## 📝 **Техническая информация:**

### **Алгоритмы шифрования:**
- **Key Exchange**: X25519 (ECDH на Curve25519)
- **LTK Derivation**: AES-CMAC
- **Session Establishment**: EAP-AKA
- **Message Encryption**: AES-128-CCM

### **Размеры ключей:**
- **LTK**: 16 байт (128 бит)
- **Session Key (CK)**: 16 байт (128 бит)
- **Nonce Prefix**: 8 байт (64 бита)
- **Private Key (X25519)**: 32 байта (256 бит)

### **Bluetooth:**
- **Service UUID**: 1A7E4024-E3ED-4464-8B7E-751E03D0DC5F
- **Restore Identifier**: "com.OmniBLE"
- **Peripheral UUID**: Генерируется iOS при первом обнаружении
